OSUZ — исправление хедера информационных страниц / 12.11.2026

Проблема: предыдущая версия копировала HTML хедера из index.html, но зависела от
трех отдельных CSS и одного JS файла. При замене только HTML браузер показывал
неоформленную шапку с дублированным поиском (в том числе на faq.html).

Исправлено:
- faq.html, returns.html, delivery.html, tariffs.html, sellers.html
- CSS и JS, необходимые для хедера, включены непосредственно в эти HTML файлы.
- Дублирование мобильного/десктопного поиска устранено стилями как в index.html.
- Меню языка, смена темы, поиск и ссылки сохранены.
- Прочие файлы проекта не изменены.

Установка: достаточно заменить ПЯТЬ HTML файлов в корне сайта. Дополнительные
assets/css или assets/js для данного исправления не нужны.

После замены выполнить Ctrl+Shift+R. Для обычных иконок Lucide, как и ранее,
используется внешний скрипт https://unpkg.com/lucide@latest; без интернета
иконки могут отсутствовать. Для работы страниц он не обязателен.

Проверка: Chromium 320/390/768/1440 px без внешних загрузок; JS node --check.
Реальное API и живые внешние шрифты/иконки не тестировались.
