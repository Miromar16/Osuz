OSUZ SEO fix — 2026-09-29

1. Public pages index.html, category.html and product.html now explicitly declare:
   robots/googlebot = index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1.
2. auth.html, cart.html and orders.html intentionally remain noindex, follow because they are account/private utility pages and should not appear in Google.
3. Product structured data is now completed in the browser from real product/listing data. It publishes offers as Offer/AggregateOffer with UZS prices. No fake reviews or ratings are added.
4. If a product has no real price/offers and no real review/rating, Product JSON-LD is omitted rather than publishing an invalid Product item.
5. Product/category canonical URLs and descriptions are synchronized after API data loads.
6. The existing robots.txt does not block public product/category pages.

IMPORTANT: DEPLOY_NOTES.txt says clean /product/... and /catalog/... URLs are generated by a separate backend routes/seo.js. That backend file is not present in this ZIP. If Search Console still reports “Excluded by noindex” for PUBLIC clean URLs after this frontend is deployed, inspect the HTTP response header X-Robots-Tag and the backend routes/seo.js template. A server-side noindex header/tag must be removed there; frontend JavaScript cannot reliably override an HTTP noindex.
