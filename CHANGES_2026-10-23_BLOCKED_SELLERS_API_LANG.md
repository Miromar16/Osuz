## Заблокированный продавец

В `cart.html` учитываются `seller.blocked`, `seller.blockedNotice`, `item.blocked` из GET `/api/site/cart`.

- Заблокированный продавец и его товары **остаются видимыми**, текст `blockedNotice` выводится без перевода и экранируется при вставке в HTML.
- Выбор продавца/товаров и изменение их количества отключены, удаление отдельного товара оставлено доступным.
- Итоговое число выбранных товаров и доступность кнопки оформления не учитывают заблокированные позиции.
- Если сервер всё-таки вернул ошибку с `code: "seller_blocked"`, выводится текст `error`, затем запрашивается свежая корзина.
- После смены языка корзина обновляется, чтобы получить `blockedNotice` на нужном языке.

## Кабинет продавца

Ссылки на старый адрес `https://osuz.uz/admin` заменены на `https://seller.osuz.uz`:

- `sellers.html` — основная кнопка и информационный блок.

Адрес `admin.osuz.uz` нигде не добавлялся. API остаётся на `osuz.uz`.

## API: ошибки по языку

Все прямые fetch-запросы к API в HTML-страницах и общих скриптах включают заголовок `X-Lang`, который читается при каждом запросе из `localStorage.osuzLang` (по умолчанию `ru`). В том числе запросы авторизации, refresh, корзины, каталога, заказов и FormData-загрузка чека. `Content-Type` для FormData не добавляется автоматически.

При обработке ошибок API предпочтение отдано полю `error`, сохраняется `code`, если сервер его вернул. Клиентские `REQUEST_TIMEOUT` и `NETWORK_ERROR` в auth.html не менялись.
