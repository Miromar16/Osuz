# OSUZ — изменения по двум инструкциям от 12 октября 2026

Изменены **только** `orders.html`, `auth.html`, `product.html` (добавлен этот файл с описанием). Существующие API и другие файлы проекта сохранены.

## auth.html — Telegram

- В профиле появился блок «Уведомления в Telegram» на RU/UZ/EN.
- Если `GET /api/site-auth/me` возвращает `telegram.linked: false`, доступна кнопка привязки; она запрашивает `POST /telegram/link` с текущим языком и открывает одноразовую ссылку на `@osuz_shop_bot`.
- Если Telegram привязан, виден статус и переключатель уведомлений (`PATCH /telegram/notify`).
- При возврате на вкладку статус привязки обновляется через `GET /me`. При ошибках сети показывается сообщение, сессия не сбрасывается.

## orders.html — оформление и отслеживание заказов

- В списке и деталях используется **строковый** `orderNumber` из API (резервный вариант: `tenantOrderNumber`, затем `orderId`). Номера вида `000042-003` сохраняют начальные нули.
- Для `pending` c `deferredUntil` выводится сообщение о закрытом магазине и времени передачи запроса при открытии.
- Для `responded` до `POST /confirm` выводится обратный отсчёт `checkoutExpiresAt`; после подтверждения он убирается.
- В момент выбора способа получения показывается предупреждение `closingSoonMinutes` / `closesAt` о скором закрытии магазина. Времена магазина выводятся в `Asia/Tashkent`.
- После подтверждения брони самовывоза (`pickupDeadline`) появилась кнопка «Забрал товар», вызывающая существующий `POST /:id/received`.
- Кнопка отмены доступна только до выбора получения, в состояниях `pending` или `responded`, как разрешено сервером.
- При отклонённых чеках доступна повторная отправка изображения; формат PDF для **новой** загрузки чека исключён (API принимает изображения до 5 МБ).
- При `payment_failed` покупатель может увидеть телефон продавца для связи (без раскрытия адреса самовывоза для доставки).
- Если покупатель ещё не связал Telegram (на основе кэшированного профиля), в ожидании продавца выводится ссылка на подключение уведомлений в `auth.html`.

## product.html — статус магазина

- В списке предложений продавцов отображается `shop_status`, полученный от API: «Открыто», «Скоро закроется», «Закрыто» (RU/UZ/EN).
- Статус не рассчитывается заново в браузере, чтобы совпадать с ботом.

## Проверка и установка

- Проверен синтаксис всех встроенных JavaScript-блоков в изменённых страницах (`node --check`).
- Проверены DOM-идентификаторы, ключевые вызовы Telegram API и формат загрузки изображений.
- Проверены вспомогательные функции для номера заказа, таймера и временной зоны на тестовых данных.
- **Не выполнялись** запросы к рабочему серверу и Telegram-боту; перед публикацией рекомендуется проверить реальный заказ и привязку Telegram под тестовым аккаунтом.
- Для установки заменить три файла в корне сайта: `auth.html`, `orders.html`, `product.html`. Или развернуть весь архив как обычную статическую сборку.
