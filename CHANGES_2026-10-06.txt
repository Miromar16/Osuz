OSUZ — правки 2026-10-06

1. Безопасность: index.html — название/бренд товара, картинка и название категории теперь экранируются (escapeHTML).
2. Мобильный «Каталог» — полноэкранный раздел (адрес #catalog, кнопка «назад» закрывает раздел), на всех 6 страницах.
3. Общие стили и скрипты вынесены из 6 HTML в /assets/css и /assets/js (подключаются с ?v=<hash>). Порядок каскада сохранён.
   HTML стали легче: 1.72 МБ -> 0.87 МБ суммарно; общий код (143 КБ) грузится и кешируется один раз.
   Внутри каждого файла блоки подписаны /* ===== id ===== */ — исходные id сохранены.
4. Выровнены расхождения между страницами: на product.html скрипт каталога был старой версией (клик по категории вёл себя иначе, чем в ТЗ V47) — теперь одинаково на всех страницах. Убрана строка, которая перезаписывала data-osuz-build устаревшей меткой.
5. Добавлены <link rel="preconnect"> для Google Fonts, cdn.tailwindcss.com, unpkg.com (index — ещё и cdnjs).
6. Tailwind больше не грузится с cdn.tailwindcss.com и не собирается в браузере: вместо этого подключён готовый
   /assets/css/tailwind.css (~30 КБ, Tailwind v3.4.17, конфиг из страниц: цвет primary-50..900, шрифт Inter).
   Ссылка стоит в конце <head>, как раньше вставлял стили CDN, поэтому порядок каскада тот же.
   Скрипты tailwind.config = {...} удалены.
   ПЕРЕСБОРКА после правок классов в HTML/JS (нужен Tailwind CLI v3.4.x, standalone-бинарник с github.com/tailwindlabs/tailwindcss/releases):
     tailwindcss -c tools/tailwind.config.js -i tools/tailwind-input.css -o assets/css/tailwind.css --minify
   (запускать из корня сайта), затем обновить ?v=… у ссылки на tailwind.css в 6 HTML.
   Новые классы Tailwind, которых нет в файлах сайта (например, если бэкенд подставляет их в HTML), в сборку не попадут.
7. Правки из init.docx (assets/css/mobile-tabbar-eyebrow-fix.css, только <768px):
   - на cart.html и orders.html скрыта надпись «Покупки» над заголовком (на десктопе остаётся);
   - индикатор активной вкладки таббара (Главная, Корзина, Заказы, Профиль, Каталог) занимает всю ширину ячейки.

ВАЖНО ПРИ ДЕПЛОЕ
- Папка /assets должна отдаваться как статика из корня сайта (пути абсолютные: /assets/css/..., /assets/js/...),
  иначе чистые адреса /product/<slug>-<id> и /catalog/<slug>-<id> останутся без стилей и скриптов.
- Бэкенд копирует product.html/category.html в образ — добавьте туда и папку assets (или раздавайте её через nginx).
- При изменении файла в assets обновите ?v=… в HTML (хеш md5 первых 8 символов содержимого).
