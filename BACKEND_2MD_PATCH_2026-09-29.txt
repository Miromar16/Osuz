OSUZ — правки по актуальному «Работа с бэкендом 2.md»

1. product.html
   - require_stock_for_cart=1: total_stock обязателен, 0 = «Нет в наличии», количество ограничено остатком.
   - require_stock_for_cart=0: total_stock игнорируется, кнопка «В корзину» активна даже при 0, количество не ограничено.
   - одинаковая логика для гостевой и авторизованной корзины.
   - ограничение количества на карточке товара применяется только при require_stock_for_cart=1.
   - JSON-LD availability не считает продавца без учёта остатков «OutOfStock» только из-за total_stock=0.

2. cart.html
   - cartStockLimits создаётся только для продавцов с require_stock_for_cart=1.
   - при require_stock_for_cart=0 лимит удаляется/не применяется.
   - гостевая корзина хранит актуальный флаг, чтобы старый maxStock не создавал ложный лимит.

SEO/ЧПУ и предыдущие исправления сохранены.
